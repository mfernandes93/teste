Olá, pessoal.

Segue um breve resumo das atividades sob minha responsabilidade no Mobius, das próximas entregas previstas e dos pontos de atenção para a continuidade operacional.

**1. Atividades atuais**

- Execução e acompanhamento das automações de abertura de contas.
- Tratamento de planilhas de contingência e inconsistências nos processos de abertura de contas e relacionamentos.
- Pendenciamento manual de demandas via BFF local.
- Cancelamento manual, via BFF, de demandas que não se encontram mais no Mobius.
- Processamento de demandas e planilhas de renovação de QSA.
- Sustentação técnica do Mobius.

2. Próximas entregas previstas**

- Para viabilizar a descontinuação do BDC, será desenvolvida a integração com o Gateway Funil, a ser disponibilizado pela squad de Abertura de Contas Atacado, para envio de dados de relacionamento via API, contemplando o mapeamento dos dados, construção do payload, autenticação e testes.
- Implementação do tratamento de erros no Mobius, permitindo a correção e o reenvio das informações pelo operador.

A demanda tinha previsão inicial de conclusão para o início de dezembro. Contudo, considerando que o refinamento do escopo ocorreu em 24/11, houve impacto no cronograma inicialmente previsto, sendo necessária a readequação do prazo de entrega.

Atualmente, aguardo o contrato da API para avanço da integração.

3. Pontos de atenção para continuidade operacional**

Embora esteja prevista a descontinuação dos processos de abertura de contas no Mobius, permanece a necessidade de sustentação até a conclusão dessa transição.

Os processos de relacionamento, renovação de QSA e sustentação do Mobius ainda demandam intervenções manuais e conhecimentos técnicos específicos, envolvendo banco de dados, código-fonte e ambiente de execução.

Mesmo com a documentação disponibilizada e as tentativas anteriores de repasse das atividades, determinadas rotinas permanecem centralizadas na minha atuação técnica.
